Memory Mediamatiker

Der Mediamatiker arbeitet in unterschiedlichen Bereichen. Finde alle Bereiche, indem du die richtigen Paare aufdeckst. Es gehören immer eine Text und eine Bildkarte zusammen.

Jedes aufgedeckte Paar gibt 100 Punkte. Für eine Serie von richtig aufgedeckten Paaren gibt es mehr Punkte. Beim 2. Paar hintereinander 200 Punkte, beim 3. Paar hintereinander 300 Punkte und so weiter.
